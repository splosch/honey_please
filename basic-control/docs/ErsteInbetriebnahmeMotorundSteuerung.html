Anlauf- & Bremsrampen (dAtA-abhängig): Die Rampenzeiten folgen den Profilen aus speed_dataset.cpp (z. B. dAtA 2: Ac 10,0 s / dc 2,0 s; dAtA 4: Ac 8,0 s / dc 1,5 s). Die Simulation skaliert diese Zeiten, behält aber die Relationen bei.

↺ Richtungswechsel im Betrieb: LINKS im Zustand LÄUFT-CW / ANLAUFEN-CW bzw. RECHTS im Zustand LÄUFT-CCW / ANLAUFEN-CCW lösen automatisch aus: proportionale Bremsrampe (aus aktuellem Rampenfortschritt) → Sicherheitspause (0,15 s) → neues Richtungsrelais (REL2/X3) → Anlauframpe mit gewähltem dAtA-Profil.

Info (Folientaster): Pins D6–D11 als INPUT_PULLUP – aktiv LOW, keine externen Widerstände nötig.

Binary-Speed Relais: D4 (M1) und D5 (M2) bilden dAtA 0/2/4/6 ab. Gelb 1 waehlt dAtA 2, Gelb 2 waehlt dAtA 4; in Standby bleibt dAtA 0 aktiv.

Verteilte Positionen: Steuerungsmodule (links) → Relais (Mitte) → Motor-Treiber (rechts) – keine Kabelkreuzungen.
